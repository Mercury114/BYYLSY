# 文法覆盖与测试设计说明

此说明用于核对本组测试的设计意图，不属于评测数据文件，不放入提交 ZIP。测试源程序共 5 个：编号 1 为唯一 A 级，编号 2、3 为两个 B 级，编号 4、5 为 C 级。每个文件都恰好包含 10 条 printf 写语句，首条只输出学号 U202441730。

| 文法成分或约束 | 覆盖位置 | 设计说明 |
| --- | --- | --- |
| CompUnit、Decl | testfile1-4 有顶层声明和函数；testfile5 只有 main | 同时覆盖顶层 Decl / FuncDef 存在与省略 |
| ConstDecl、VarDecl、BType | testfile1-3，testfile4 | const 与 var 声明、int 类型、多定义项和单定义项 |
| ConstDef、ConstInitVal、ConstExp | testfile1 的标量常量，testfile2 的一维常量数组，testfile3 的二维常量数组 | 覆盖标量、一维、二维常量定义；数组维度使用常量标识符 |
| VarDef、InitVal | testfile2 的一维数组及二维数组初始化，testfile3 的二维数组，testfile4/testfile5 的标量变量 | 覆盖有无初始化、标量和数组、表达式初值及分层花括号初值 |
| FuncDef、MainFuncDef、FuncType | testfile1-4 | int / void 函数；有形参、无形参；主函数均返回 0 |

| Block、BlockItem | testfile4 的空函数体、空语句块、含声明与语句的块 | 覆盖空块和非空块，块内声明与语句交错 |
| 赋值、表达式语句、空语句、语句块 | testfile1-5，重点 testfile4 | 左值赋值、表达式后接分号、单独分号以及块语句 |

## 关键运行结果核对

testfile1 的 probe 函数会增加全局 visits。0 && probe(8) 与 1 || probe(7) 的右侧调用应被短路；!0 && probe(1) 则应调用一次 probe。后续运算再调用一次，因此相应输出中的计数依次为 0、0、2、2。该用例将短路行为转化为可观察的输出，避免只覆盖逻辑运算符而无法辨别求值方式。

testfile2 输入为 4 5 6，输出数组输入值、求和结果、常量数组运算、二维数组元素组合、函数组合调用和更新结果。testfile3 输入为 1 2 3 4，验证二维数组整体传参、某一行作为一维数组实参、数组参数修改以及二维常量数组读取。testfile4 输入为 9，检查块、空语句、表达式语句、getint 赋值和不同返回形式。testfile5 不读取输入，集中核对算术、关系比较和相等性判断。

所有 outputN.txt 的每一行都在换行前保留一个尾随空格，与各 printf 格式串中的末尾空格一致。input1.txt 和 input5.txt 是零字节空文件。
