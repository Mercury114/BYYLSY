# 实验三：语义分析与 MIPS 代码生成报告参考

> 本文按实验报告的五个章节整理，供撰写时参考。当前提交实现为 C11 版本，源文件为 `src/compiler.c`。请根据自己实际完成的调试过程修改“实验心得体会”，并以课程平台最终评测结果为准。

## **一、实验内容**

本实验在词法分析和语法分析的基础上，增加标量常量、变量、表达式、赋值、读入和输出语句的语义处理，并将源程序翻译为四元式中间代码，再生成 MIPS 汇编。编译器从固定文件 `testfile.txt` 读取源代码，将汇编写入 `mips.txt`；编译阶段不读取标准输入。生成的 MIPS 程序运行时通过 MARS 系统调用读取输入并输出结果。

作业说明限定本次测试程序不包含普通函数定义和调用、数组声明及引用，主要检查常量说明、变量说明、赋值、读语句和写语句。实现兼容题目样例中的 `scanf(x);`，也兼容前序文法中的 `x = getint();`。`printf` 支持格式字符串中的 `%d` 和 `\\n`，也支持直接输出整数表达式。

## **二、实验设计**

### 2.1 编译流程

程序分为词法分析、递归下降语法分析与语义检查、四元式生成、MIPS 生成四个阶段。词法分析产生带有类别、原始词素、单词值和行号的 Token；语法分析时查询符号表，并在识别表达式或语句的过程中生成四元式；MIPS 生成器遍历四元式，输出 `.data` 和 `.text` 段。评测所需的输出文件为 `mips.txt`，四元式默认只保存在内存中。

程序入口为 C 函数 `main`，不依赖 Java、第三方库或标准输入。评测环境可用 `clang -std=c11` 编译 `src/compiler.c`。编译器只处理当前目录下的 `testfile.txt`，不会把被编译程序运行时所需的输入读进来。

### 2.2 符号表与语义检查

符号表记录标识符名称、唯一存储标签、常量属性、常量值和声明行号。变量分配独立的 `vN` 数据标签；常量值在编译阶段记录，引用时以立即数形式进入四元式。变量和临时量在 MIPS 数据段中分配存储位置。

语义检查覆盖重复定义、未定义标识符、给常量赋值、常量初值引用非常量变量、`printf` 格式串缺少对应实参，以及本次作业范围之外的数组和普通函数调用。`printf` 中的 `%d` 按顺序消费实参；格式串处理完成后，剩余实参继续按顺序输出。发现词法、语法或语义错误时，程序报告行号并清空 `mips.txt`，避免留下上次运行生成的汇编文件。

### 2.3 四元式与表达式翻译

四元式采用 `(op, arg1, arg2, result)` 形式。立即数以前缀 `#` 表示，变量以前缀 `@` 表示，临时量以前缀 `%` 表示。主要操作如下：

| 四元式 | 含义 | MIPS 实现 |
| --- | --- | --- |
| `(ADD, a, b, t)`、`(SUB, a, b, t)` | 加、减 | `addu`、`subu` |
| `(MUL, a, b, t)` | 乘法 | `mult`、`mflo` |
| `(DIV, a, b, t)`、`(MOD, a, b, t)` | 有符号除法、取余 | `div` 后读取 `mflo` 或 `mfhi` |
| `(NEG, a, _, t)`、`(POS, a, _, t)` | 一元负号、一元正号 | `subu` 或 `move` |
| `(ASSIGN, a, _, v)` | 赋值或变量初始化 | 加载操作数后 `sw` |
| `(READ, _, _, v)` | 读入整数 | syscall 5，保存 `$v0` |
| `(PRINT_INT, a, _, _)` | 输出整数 | syscall 1 |
| `(PRINT_STRING, s, _, _)` | 输出字符串片段 | syscall 4 |
| `(HALT, _, _, _)` | 程序结束 | syscall 10 |

表达式分析按括号、一元运算、乘除模、加减的优先级递归。普通表达式的运算结果写入临时量；常量声明使用常量表达式模式，在编译期计算并拒绝非常量操作数。MIPS 生成阶段为变量和临时量安排 `.word` 存储，并用 `$t0`、`$t1`、`$t2` 等临时寄存器完成运算。

### 2.4 输入输出与优化接口

读语句生成 MARS syscall 5；这与编译器自身读取 `testfile.txt` 相互独立。字符串片段以 UTF-8 字节形式放入数据段并以零字节结尾，运行时由 syscall 4 输出；整数由 syscall 1 输出。`printf("label = ", value)` 会先输出格式串，再输出未被 `%d` 消费的整数实参，以兼容本次测试文件的写法。格式串支持普通可打印字符（包含单引号）、`%d` 和 `\\n`。若一次 `printf` 的格式串没有以 `\\n` 结尾，生成代码会在该语句输出后补换行；格式串已显式以 `\\n` 结尾时不会重复添加。

优化默认关闭。设置环境变量 `COMPILER_OPTIMIZE=1` 可启用当前的冗余自赋值删除优化。中间代码导出默认关闭；设置 `COMPILER_IR_BEFORE` 和 `COMPILER_IR_AFTER` 环境变量为文件路径后，可分别导出优化前、优化后的四元式，为后续优化作业保留接口。

本地编译器可按下列方式编译并运行：

```text
clang -std=c11 -O2 src/compiler.c -o compiler
./compiler
java -jar Mars.jar nc sm mips.txt
```

前两条命令在包含 `testfile.txt` 的目录执行，第二条命令生成 `mips.txt`；第三条命令使用 MARS 汇编并运行生成的代码。MARS 所需的运行时输入应提供给 MARS 进程，而不是编译器进程。若在 Windows 命令提示符下测试，可将可执行文件名替换为 `compiler.exe`。

## **三、实验过程**

1. 整理本次作业所需的词法单元，识别关键字、标识符、整数、字符串、运算符和界符，同时记录单词值及行号。
2. 使用递归下降方法分析本次作业涉及的声明、表达式和语句，并在分析时维护符号表和检查标识符的定义及可写性。
3. 将表达式和语句翻译为四元式：算术表达式生成运算四元式，变量初始化和赋值生成 `ASSIGN`，读写语句分别生成 `READ`、`PRINT_INT` 和 `PRINT_STRING`。
4. 根据四元式生成 MIPS 数据段和指令段，为变量、临时量和字符串安排标签，并将算术运算映射为 MIPS 指令及 syscall。
5. 使用 MARS 4.5 汇编并运行题目样例、算术表达式、一元运算、`getint()` 和长字符串等程序，检查生成代码与预期输出。
6. 分别验证优化关闭和开启的代码路径，以及优化前后四元式的文件导出接口；另用常量赋值、整数前导零等错误输入检查行号报告和输出清理。
7. 将提交 ZIP 整理为仅包含 `src/compiler.c` 的源码包；测试文件和本报告保留在压缩包之外。

## **四、实验结果与分析**

提交源文件采用 C11 编写，入口为 `main`，目标评测编译方式为 `clang -std=c11`。本地测试使用课程提供的 MARS 4.5 汇编和运行 MIPS 代码，五个有效测试程序的输出与预期一致：

| 测试 | 覆盖内容 | MARS 输出 |
| --- | --- | --- |
| 题目样例 | 全局变量、字符串输出、`scanf` 读入、整数输出 | `Hello World`；`1837` |
| 算术用例 | const、全局/局部变量、初始化、优先级、`+ - * / %`、格式化输出 | `x=11, y=3`；`4` |
| 一元表达式用例 | 括号、一元负号与正号、带格式换行的 `%d` | `v=-4` |
| `getint` 用例 | `x=getint()`、变量乘法和整数输出 | `42` |
| 长字符串用例 | 较长字符串的输出及换行 | 与测试预期一致 |

算术用例包含已初始化变量的自赋值。优化关闭时生成 19 条四元式，开启后删除该条冗余赋值，得到 18 条；两种模式在 MARS 中的运行输出相同。错误输入测试还覆盖常量赋值和整数前导零，程序会报告对应行号并清空汇编输出。

以上为本地验证结果，不等同于课程平台的最终评分。提交后应核对平台状态及差异信息；若评测机仍报告编译入口问题，应确认上传的 ZIP 内路径为 `src/compiler.c`，且其中包含 C 的 `main` 函数。

## **五、实验心得体会**

本次实验让我看到语义分析和代码生成之间的衔接方式。符号表把源程序中的名字对应到常量值或唯一存储标签，语法制导翻译则将表达式和语句逐步转换为四元式。中间代码独立于目标机器，之后由 MIPS 生成器处理存储、算术和系统调用，这让后续增加优化时更容易定位问题。

调试时需要区分编译器输入和被编译程序的输入：编译器只读取源文件，而 `scanf` 或 `getint` 对应的数据由生成的 MIPS 程序在 MARS 中读取。输出换行同样属于结果的一部分，因此要同时考虑格式串中的显式换行和写语句结束时的换行处理。

后续可在现有四元式接口上继续扩展控制流、函数调用、数组和更多优化，并分别验证中间代码和目标代码。正式报告中应补充本人实际遇到的问题、调试过程和课程平台的评测结果。
